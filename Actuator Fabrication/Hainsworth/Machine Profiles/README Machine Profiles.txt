This folder should contain files or information that describe machine and/or material profiles, such as .3mf, .goo, .ctb, etc.

gcode or equivalent manufacturing files should also be stored in this folder.


For FDM/FFF Printed Actuators: 

	Models were sliced with PrusaSlicer 2.9.2. 

	Material and print profiles are included in the .3mf files. Import these files in the Prusa Slicer, then save the print settings preset and material preset for future use. 

	As of December 2025, 2 materials were used to FFF print all actuators tested. For each material, the print settings did not change for new actuator designs. Print setting changes may be needed for different actuator designs, but they were unnecessary for the actuators tested. To be clear: actuators made of the same material were printed with the same settings. 

The Hainsworth actuator was printed on a Prusa MK4S after slicing with PrusaSlicer v2.9.2 . 

To re-use the same settings and model: 
Download the .3mf file, then in Prusa Slicer click File > Open Project > (ActuatorName).3mf . Save the print settings and filament settings as a preset for later use.
